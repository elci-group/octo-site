What just happened

No deploy ran to produce this page. The Chrome extension asked the local grow daemon to resolve a grow:// URL; the daemon cloned elci-group/octo-site over https, recorded the verified HEAD commit in the local registry, and started serving the commit tree on a localhost port.

If the repository moves on, grow refuses to run the drifted state until it is re-installed and re-verified — the same discipline as every other grow app.
